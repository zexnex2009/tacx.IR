# Welcome to Tacx.IR! 🇧🇩

Welcome to the world of programming! If you've never written a line of code before, you're in the perfect place. 

## What is Tacx.IR?

**Tacx.IR** is a programming language designed to feel like **Banglish** (Bengali written in English letters). 

Imagine you are talking to a very literal-minded robot. In most programming languages, you have to speak "Robot-ish" (like `let x = 10` or `print("Hello")`). In Tacx.IR, you talk to the robot in a way that feels more natural if you know Banglish!

**Note: Tacx.IR keywords are matched case-insensitively; lowercase remains the canonical style.**

Instead of `print`, we say **`bolo`** (Tell/Say).
Instead of `if`, we say **`jodi`** (If).

## Why learn to program?

Programming is just **problem-solving**. It's like writing a recipe for a kitchen. You give the computer a list of instructions, and it follows them exactly. 

Learning Tacx.IR will teach you the "Logic" of programming, which is the same in almost every other language like Python, JavaScript, or C++.
